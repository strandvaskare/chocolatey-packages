# chocolatey-packages

Chocolatey packages maintained by V Squared Workshop.

| Package | Description |
|---|---|
| [revit2027](revit2027/) | Autodesk Revit 2027, installed side by side with other Revit versions. Never removes other Revit years or add-ons. |
| [revit2024](revit2024/) | Autodesk Revit 2024, installed side by side with other Revit versions. Never removes other Revit years or add-ons. |

Packages contain only install scripts and metadata. Software is downloaded from the vendor's official distribution servers and verified by checksum at install time.
